# Pi package catalog research (Pi 1.4.0)

## Summary

**Best first trials (not automatic installs):** [`@narumitw/pi-usage`](https://github.com/narumiruna/pi-extensions/blob/main/packages/pi-usage/README.md) for Codex limits, [`pi-context-view`](https://github.com/dimk90/pi-context-view#readme) to diagnose the many skill/extension injections, and [`@plannotator/pi-extension`](https://github.com/backnotprop/plannotator#readme) for human plan/diff annotation. Then evaluate **one at a time**: [`@narumitw/pi-plan-mode`](https://github.com/narumiruna/pi-extensions/blob/main/packages/pi-plan-mode/README.md), [`pi-lens`](https://github.com/apmantza/pi-lens#readme), and [`pi-btw`](https://github.com/dbachelder/pi-btw#readme). Conditional, not defaults: [`pi-mcp-adapter`](https://github.com/nicobailon/pi-mcp-adapter#readme) only if MCP is genuinely used, [`pi-cache-optimizer`](https://github.com/jiangge/pi-cache-optimizer#readme) if actual cache overhead emerges. Preserve the seven existing choices pending integration tests; specifically check permission handling inside tintinweb child agents and future Claude CLI subscription billing. Existing `pi-footer` is optional ergonomics; keep `pi-pretty@0.6.29` until a controlled 1.4.0 trial of current 0.8.0. [Sources and ranking below](#ranked-shortlist).

## Catalog format and discovery

Observed 2026-10-25 UTC: [catalog](https://pi.dev/packages) renders server-side HTML; 50 cards on page 1 with links to page 108 (at time checked), filters `name`, `type` (`extension`, `skill`, `theme`, `prompt`), `sort` (`downloads`, `recent`, `name`) and `page`. Cards expose monthly downloads, publish recency, type and links to npm/repo. A probe of [`/api/packages`](https://pi.dev/api/packages) returned HTTP 501 JSON (`API routes are reserved for future features.`), not a usable catalog endpoint; `/packages.json` returned 404. Use HTML/filter rather than assuming a catalog API. These counts/ages are volatile. [Catalog](https://pi.dev/packages), [page 2](https://pi.dev/packages?page=2).

## Notable skips

These are **not** claims of defects; descriptions are from the linked official catalog/first-party repositories, and judgments reflect Ivan's known setup.
